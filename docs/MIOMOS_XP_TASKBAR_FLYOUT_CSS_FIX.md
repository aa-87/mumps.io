# MIOMOS XP taskbar/start menu CSS fix

This patch adds a full in-template CSS block for the current MIOMOS desktop shell markup.

It covers the previously missing classes for:
- `miomos-taskbar-flyout`
- `miomos-taskbar-utility-btn`
- `miomos-account-menu-item`
- `miomos-notice-item`
- `miomos-start-menu*`
- `miomos-start-footer-btn`
- `miomos-start-side-link`
- `miomos-quicklaunch*`
- `miomos-taskbar*`
- `miomos-shell-dialog*`
- `miomos-context-menu*`
- `miomos-terminal-*`
- core window, desktop icon, chip, button, and shell alert classes

The visual goal is a visible Windows XP classic-inspired taskbar and Start menu with correctly rendered taskbar flyouts.
