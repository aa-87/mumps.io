# MIOUI Layout Overlays Plan

## Goal

Add overlay-first layout systems for high-intensity data applications.

## Surfaces

- Layout transition bar
- Snapshot restore gallery
- Cross-route workspace map
- Emergency focus layout
- Shift handoff layout
- Overlay density matrix

## Why this ROI matters

Dense applications do not stay in one shell. Operators move between triage, audit, handoff, analytics, and urgent single-item review. This ROI makes those shifts visible and predictable.
