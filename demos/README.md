# MIOTPL Adoption Pack

This package contains two adoption-focused deliverables:

## ROI #1 — “5-minute success” starter kit

- `starter-kit/` contains a copy/paste demo that renders a page with layout + blocks + partials.

## ROI #2 — Advanced “wow” demo

- `advanced-demo/` is a web-app-shaped example showing layout blocks, component partials, dynamic partial selection, and a safe playground pattern.

## Docs

- `docs/` includes the existing user/integration/security/testing docs plus LLM-oriented generation guidance.

## Benchmarks

- `MIOTPLB.m` measures compile/render times and output sizes.
