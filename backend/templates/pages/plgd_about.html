What this app is

MIOPLGD is a server-rendered template playground powered by MIOTPL. It includes a built-in library (seeded on first run), allows saving custom templates to ^MIO("PLGD",...), and provides APIs for render/save/favorite/export/import.

Security defaults

  • No untrusted lambdas: scalar values beginning with $$ are stripped before rendering.
  • Sandboxed ad-hoc render: ad-hoc templates block {{>}} partials and {{<}} inheritance by default.
  • Recursion limits: CONF("templates","maxPartialDepth") is set conservatively.

API quick reference

POST /plgd/api/render → template + json → text/plain
POST /plgd/api/save → save template in ^MIO → JSON
POST /plgd/api/fav → toggle favorite → JSON
POST /plgd/api/export → export library → JSON
POST /plgd/api/import → import library → JSON
