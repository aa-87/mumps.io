# MIOTPL Starter Kit (5-minute success)

This starter kit is designed to maximize adoption: copy templates, run one command, see a real HTML page.

## Quick start

1) Copy templates:

- `starter-kit/templates/` → `templates/`

2) Copy routine:

- `starter-kit/routines/MIOTPL5MIN.m` → your routine path

3) Run:

```mumps
ZL "MIOTPL","MIOTPL5MIN"
D RUN^MIOTPL5MIN
```

If you see a complete HTML page printed to your terminal, you’re done.

## What to edit next

- `templates/pages/home.html` – page content
- `templates/layouts/app_layout.html` – shared layout
- `templates/partials/ui_card.html` – reusable component
