What is MIOPLGD?

MIOPLGD is a MIOTPL-powered template playground with a reusable library. It is designed for data-heavy workflows: compact UI, fast iteration, and strong safety defaults.

Use the Playground to edit a template + JSON context, render instantly, inspect output in multiple modes, and keep render history + diffs. Save templates to the Library and manage versions with rollback.

Shortcuts

Ctrl+Enter  Render
Ctrl+S      Save
Alt+F       Toggle favorite

Theme is persisted locally. Version history is stored server-side in ^MIO("PLGD","tpl",id,"rev",...).

Safety defaults

  • Untrusted lambdas (scalars starting with $$) are stripped from JSON context.
  • Ad-hoc renders reject partials / inheritance by default.

APIs

POST /plgd/api/render
POST /plgd/api/save
POST /plgd/api/fav
POST /plgd/api/revs
POST /plgd/api/revget
POST /plgd/api/rollback
